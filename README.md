# 杨舒晴 · 个人在线简历

北京林业大学 生物科学专业 · 个人在线简历项目

## 文件结构

```
resume/
├── index.html          # 简历主页面
├── css/
│   └── style.css        # 样式表（响应式布局、配色、动画）
├── js/
│   └── script.js         # 交互脚本（滚动动画、导航、返回顶部）
├── assets/               # 预留图片资源目录（如需添加个人照片，放在这里）
└── README.md             # 项目说明
```

## 设计说明

- **设计概念**：以生物学"标本卡 / 野外笔记本"为视觉主题，呼应生物科学专业背景
- **配色**：森林绿 + 琥珀色为主色调
- **字体**：中文衬线（Noto Serif SC）作标题，无衬线（Noto Sans SC）作正文，等宽字体（JetBrains Mono）作标签与数据
- **响应式**：桌面端两栏布局，移动端自动收起为单栏，导航栏在移动端隐藏

## 交互与动效（加分项）

- 页面滚动进度条
- 姓名逐字浮现的入场动画
- 滚动触发的区块淡入效果（Intersection Observer）
- 卡片悬停微交互（技能卡片、爱好卡片、标签）
- 固定导航栏（滚动后出现，点击平滑跳转）
- 返回顶部按钮
- 已适配 `prefers-reduced-motion`，尊重用户的减少动效系统设置

## 本地预览

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或启动服务器。

## 部署到线上（可选加分项）

### 方式一：GitHub Pages
1. 在 GitHub 新建一个仓库，将本项目文件全部上传
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支 / 根目录，保存
4. 几分钟后即可通过 `https://你的用户名.github.io/仓库名/` 访问

### 方式二：Vercel
1. 注册 [vercel.com](https://vercel.com) 并连接 GitHub 仓库
2. 导入本项目仓库，Framework Preset 选择 "Other"
3. 直接部署，无需额外构建配置
4. 部署完成后会自动生成一个 `.vercel.app` 域名

### 方式三：Netlify
1. 注册 [netlify.com](https://netlify.com)
2. 将整个项目文件夹直接拖拽到 Netlify 的部署页面（Drag and drop）
3. 几秒钟即可生成一个可访问的网址

部署完成后，记得把生成的网址附在提交文档中。
